## Source Document Summary

### World Architect Session 001
Key decisions extracted for requirements:
- Setting: Geological Fantasy, world called Dern Varath ("the Old Dark")
- Four civilizations with distinct visual identities: Varekian Compact (delta engineers), Ashbound (volcanic theocrats), Deepwalkers (underground scholars), Tide Compact (coastal confederation)
- Four biomes: Varek Delta (default start), Scorch Plateau, Deepwalker Karst, Shatter Coast
- The Fracturing as central world event — 400 years of geological consequence
- Anchor Network as the Founders' legacy — ancient geological suppression installations now in ruins
- Historical Ledger as NPC faction-memory system, with Legend Layer decay
- Procedural generation: pressure-triggered via tectonic, demographic, and catastrophe thresholds

### Mechanic Designer Session 001
Key decisions extracted for requirements:
- Core loop: Read → Act → Mark (three-phase cycle)
- Terrain Stance System: four stances aligned to biomes/factions, each requiring a 3-second channel
- Geological Discipline system: Reading, Shaping, Resonance, Charting — Strata depth 1–50
- Economy: active extraction with depletion, three-tier crafting (Raw Processing / Geological Crafting / Synthesis), physically-located markets with no global AH
- Land: three-tier system (Exploration Rights / Claim Stakes / Development Rights)
- New player experience: arrival in media res, no tutorial boxes, ferryman NPC speech references local conditions
- Historical Ledger in the first 30 minutes: visible at dock notice board

### GDD v0.1
Authoritative specification for all systems. GDD section references embedded in each REQ file. Key formal specifications used:
- Terrain Stance specifications (Section 4.2)
- Geological Discipline Strata tiers: Surface/Formation/Mantle/Core (Section 3.3)
- Extraction method mechanics table (Section 5.1)
- Crafting tier structure (Section 5.2)
- Market type table (Section 5.3)
- Claim Stake rules — 72-hour expiry, 12-hour undefended window (Section 6.2)
- Historical Ledger entry format (Section 7.2)
- Legend Layer rules (Section 7.3)
- First 30 minutes scripted moment-by-moment (Section 8.2)

## Design Decisions Made During Requirements Production

### Placeholder data decisions
All requirements use consistent named data across the batch to create a coherent world impression across mockups:
- Player character: "KAEL DURST" — Varekian Compact, Reading discipline, Formation Understanding Strata 17
- Resource node: "Eastern Salt Crystal Formation — Node ESF-7"
- Claim stake holder: "MIRA ASHVEN — Compact Claim"
- Ferryman NPC: "Aldric Vane, River Ferry"
- Varekian factor: "Factor Merik Holst"
- Transport company: "Doven Salt Company"
- In-world date: "14th Tide-Turn, Year 423 Post-Fracturing"
- Channel event: "Northern Channel blocked — sandbar formation — Day 3"
These consistent data elements create a coherent world-state snapshot across all mockups.

### Faction aesthetic embedding
Every Claude Artifact Prompt fully embeds the relevant faction aesthetic specifications verbatim. Claude.ai has no project memory; all visual constraints are self-contained within each prompt. The four faction palettes are embedded in each prompt where that faction's visual identity is relevant.

### Phase 1 surface selection justification
The seven Phase 1 surfaces represent the minimum viable design vocabulary for a Phase 1 prototype:
- REQ-001 (Game HUD): required to build any in-play prototype session
- REQ-002 (Terrain Stance indicator): the core combat differentiator; must be designed before combat prototyping
- REQ-003 (Ledger notice board): the game's persistence system made visible; required for onboarding design validation
- REQ-004 (Character creation): the first consequential player choice; required before any playtesting
- REQ-005 (New player arrival): the onboarding moment; required to validate the no-tutorial-box design principle
- REQ-006 (Logo/wordmark): required for any external communication, investor materials, or build environments
- REQ-007 (Login/loading): the first impression before the game begins; required before any external testing

### Cross-REQ consistency notes
- REQ-001 (Game HUD) and REQ-014 (Deepwalker HUD variant) share the same functional element list — they are explicitly designed as a comparison pair
- REQ-003 (Ledger notice board) and REQ-005 (new player arrival) share world-state data (same channel blockage event, same dock context) — the notice board in REQ-003 is the same board referenced in REQ-005
- REQ-009 (node depletion overlay) references the same node (ESF-7) as REQ-011 (zone map overlay) and REQ-012 (geological legacy record)
- REQ-010 (regional market) price data references the same channel blockage event visible across multiple REQs

### Anti-pattern enforcement
The following anti-patterns were explicitly prohibited in every relevant requirement:
- Generic fantasy gold filigree UI
- Floating arcane runes without geological grounding
- Purple/void magic color language
- Neon or electric glow effects
- Generic MMO UI aesthetic (WoW-style health/mana bars, floating quest markers, etc.)
- Non-geological magic visual language (fire effects, lightning, arcane sparkle)

## Open Questions Flagged (Not Blocking Batch)

These questions arose during requirements writing and are relevant to future design passes:

**DQ-001: Varekian Compact currency notation**
The GDD does not specify the currency system. Mechanic Designer Session 001 implies a commodity-backed economy. REQ-010 introduces "Compact Tallies (CT)" as a placeholder. This requires System Designer confirmation before REQ-010 artifact is used in actual economy prototyping.

**DQ-002: Terrain Stance channel visual language**
REQ-002 specifies the 3-second channel animation as geological in character (crystal spreading, not a spinner). The specific animation implementation is a Phase 1 tech question. The prompt provides directional guidance but the actual implementation requires Tech/Art validation.

**DQ-003: Underground depth indicator units**
REQ-014 (Deepwalker HUD) introduces a depth-below-surface indicator showing "312 meters." No GDD specification exists for how underground depth is measured or communicated to players. This is a new system surface that requires design specification.

**DQ-004: Faction-neutral HUD skin for unaffiliated players**
REQ-001 specifies the Varekian Compact HUD as default. REQ-004 (faction selection) shows that players can start unaffiliated. There is no specified HUD skin for unaffiliated players — this is a gap requiring a Phase 1 design decision.
