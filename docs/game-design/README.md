## Document Standard

Each GDD section follows this structure:

1. **Overview** — one paragraph summary
2. **Player Goal** — what the player is trying to do
3. **Core Loop** — step-by-step moment-to-moment experience
4. **Systems** — detailed rules, formulas, inputs/outputs
5. **Edge Cases** — unusual scenarios and how to handle them
6. **Open Questions** — unresolved design decisions
7. **Dependencies** — other systems this interacts with
